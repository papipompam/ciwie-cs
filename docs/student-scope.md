# ขอบเขตระบบสำหรับนักศึกษา

ระบบนี้ใช้สำหรับนักศึกษาสาขาวิทยาการคอมพิวเตอร์ และทำหน้าที่บันทึกกับติดตามการหาสถานที่ฝึกงาน ระบบไม่ได้สมัครหรือติดต่อสถานประกอบการแทนนักศึกษา

## 1. บัญชีผู้ใช้งาน

นักศึกษาสามารถ:

- เปิดใช้งานบัญชีด้วยรหัสนักศึกษาและรหัสเปิดใช้งาน
- ตั้งรหัสผ่านด้วยตนเอง
- เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน
- ออกจากระบบ
- ดูข้อมูลส่วนตัว
- แก้ไขหมายเลขโทรศัพท์ อีเมลส่วนตัว หรือข้อมูลติดต่อที่ได้รับอนุญาต
- เปลี่ยนรหัสผ่าน
- ขอให้ผู้ดูแลระบบช่วยรีเซ็ตรหัสผ่านเมื่อจำรหัสผ่านไม่ได้

ข้อมูลการศึกษา เช่น รหัสนักศึกษา ชื่อ นามสกุล และปีที่เข้าศึกษา นักศึกษาไม่สามารถแก้ไขเองได้

## 2. บันทึกสถานประกอบการที่สมัคร

นักศึกษาต้องสมัครกับสถานประกอบการภายนอกด้วยตนเอง แล้วจึงนำข้อมูลมาบันทึกในระบบ

ข้อมูลที่ต้องบันทึกประกอบด้วย:

- ชื่อสถานประกอบการ
- ที่อยู่
- จังหวัด
- ตำแหน่งที่สมัคร
- วันที่ยื่นสมัคร
- ชื่อผู้ติดต่อในสถานประกอบการ
- ตำแหน่งผู้ติดต่อ ถ้ามี
- หมายเลขโทรศัพท์
- อีเมล
- ช่องทางติดต่ออื่น
- หมายเหตุ

นักศึกษาสามารถ:

- บันทึกสถานประกอบการที่สมัครได้หลายแห่ง
- ดูรายการสถานประกอบการที่ตนเองสมัคร
- แก้ไขข้อมูลที่บันทึกผิด
- ลบรายการที่สร้างผิด หากรายการนั้นยังไม่ถูกนำไปออกหนังสือ
- ดูประวัติการสมัครย้อนหลัง

ระบบควรแจ้งเตือนเมื่อพบชื่อสถานประกอบการคล้ายกับข้อมูลเดิม แต่ต้องไม่รวมข้อมูลให้อัตโนมัติ

## 3. บันทึกและติดตามสถานะการสมัคร

นักศึกษาสามารถปรับปรุงสถานะของแต่ละสถานประกอบการตามผลที่ได้รับจริง

สถานะการสมัครประกอบด้วย:

1. `SUBMITTED` — ยื่นสมัครแล้ว
2. `WAITING_RESPONSE` — รอการตอบกลับ
3. `INTERVIEW_PENDING` — รอสัมภาษณ์
4. `PRELIMINARY_ACCEPTED` — สถานประกอบการแจ้งตอบรับเบื้องต้น แต่ยังไม่ถือว่าเป็นสถานที่ฝึกงานที่ยืนยันแล้ว
5. `REJECTED` — สถานประกอบการปฏิเสธ
6. `CANCELLED` — ยกเลิกการสมัคร

นักศึกษาสามารถ:

- เปลี่ยนสถานะการสมัคร
- บันทึกวันที่ได้รับผลจากสถานประกอบการ
- เพิ่มหมายเหตุ
- แนบหลักฐานการติดต่อหรือผลตอบกลับ ถ้ามี
- ดูประวัติการเปลี่ยนสถานะ
- ดูว่าใครแก้ไขสถานะและแก้ไขเมื่อใด

ผู้ดูแลระบบและอาจารย์สามารถตรวจสอบและแก้ไขข้อมูลที่นักศึกษาบันทึกผิดได้

## 4. ขอให้ออกหนังสือ

เมื่อต้องการดำเนินการกับสถานประกอบการแห่งใด นักศึกษาสามารถ:

- เลือกสถานประกอบการจากรายการที่ตนเองบันทึกไว้
- ตรวจสอบข้อมูลสถานประกอบการและผู้ติดต่อ
- แก้ไขข้อมูลก่อนส่งคำขอ
- ส่งคำขอให้ออกหนังสือ
- ดูสถานะการดำเนินการ
- ดูหรือดาวน์โหลดหนังสือเมื่อได้รับอนุญาต

สถานะคำขอจัดทำเอกสารประกอบด้วย:

1. `REQUESTED` — ส่งคำขอแล้ว
2. `IN_PROGRESS` — อยู่ระหว่างตรวจสอบและจัดทำเอกสาร
3. `READY_TO_SEND` — เอกสารพร้อมนำส่ง

คำขอเป็นข้อมูลรายนักศึกษาและมีประวัติของตนเอง ผู้ดูแลระบบหรืออาจารย์สามารถนำคำขอของนักศึกษาหลายคนที่ไปสถานประกอบการหรือสถานที่ปฏิบัติงานเดียวกันในรอบสหกิจเดียวกันไปเชื่อมกับชุดเอกสารเดียวกันได้ โดยไม่รวมและไม่ลบประวัติคำขอรายคน

ผู้ดูแลระบบหรืออาจารย์เป็นผู้:

- ตรวจสอบข้อมูล
- ออกเลขหนังสือ
- สร้างหนังสือขอความอนุเคราะห์
- แนบแบบตอบรับ
- ส่งเอกสารหรือมอบเอกสารให้นักศึกษานำส่ง

นักศึกษาไม่สามารถออกเลขหนังสือหรือแก้ไขหนังสือที่ออกแล้ว

## 5. ติดตามการส่งหนังสือ

หากผู้ดูแลระบบหรืออาจารย์เป็นผู้ส่งเอกสาร บุคคลนั้นต้องเป็นผู้บันทึกสถานะ โดยนักศึกษาสามารถดูความคืบหน้าได้

หากนักศึกษาเป็นผู้นำส่ง นักศึกษาสามารถบันทึก:

- ส่งเอกสารแล้วหรือยัง
- วันที่ส่ง
- ช่องทางการส่ง
- ผู้รับเอกสาร ถ้าทราบ
- หมายเหตุ
- หลักฐานการส่ง ถ้ามี

สถานะการนำส่งเอกสารประกอบด้วย:

1. `SENT` — ส่งเอกสารให้สถานประกอบการแล้ว
2. `WAITING_RESPONSE` — รอแบบตอบรับ
3. `RESPONSE_RECEIVED` — ได้รับแบบตอบรับแล้ว

ระบบต้องเก็บผู้เปลี่ยนสถานะและเวลาที่เปลี่ยนทุกครั้ง

## 6. บันทึกแบบตอบรับจากสถานประกอบการ

เมื่อสถานประกอบการส่งแบบตอบรับกลับมา นักศึกษาสามารถบันทึก:

- สถานประกอบการที่ตอบกลับ
- วันที่สถานประกอบการตอบกลับ
- ผลการตอบรับของสมาชิกแต่ละคน ได้แก่ `ACCEPTED` หรือ `DECLINED` ตามที่ระบุในแบบตอบรับ
- จำนวนที่สถานประกอบการสามารถรับได้ ถ้ามี
- เงื่อนไขเพิ่มเติม
- หมายเหตุ
- ไฟล์แบบตอบรับ

หากหนังสือหนึ่งชุดมีนักศึกษาหลายคน:

- นักศึกษาคนใดคนหนึ่งในชุดสามารถอัปโหลดแบบตอบรับและกรอกผลรายคนแทนชุดเป็นฉบับร่างได้
- นักศึกษาทุกคนในชุดสามารถดูแบบตอบรับฉบับเดียวกันได้
- ผลยินดีรับหรือไม่สามารถรับต้องบันทึกแยกเป็นรายนักศึกษา
- ผู้อัปโหลดต้องส่งฉบับร่างให้ Lecturer หรือ Admin ตรวจ และไม่ถือว่าผลได้รับการยืนยันเพียงเพราะนักศึกษากรอกข้อมูลแล้ว

สถานะการตรวจแบบตอบรับประกอบด้วย:

1. `DRAFT` — ผู้อัปโหลดยังกรอกข้อมูลหรือผลรายคนไม่ครบ
2. `PENDING_REVIEW` — ส่งให้ Lecturer หรือ Admin ตรวจแล้ว
3. `CONFIRMED` — Lecturer หรือ Admin ยืนยันผลสมาชิกทั้งชุดแล้ว

นักศึกษาแก้ไขได้ในสถานะ `DRAFT` เมื่อส่งตรวจแล้วจะแก้ไขไม่ได้จนกว่า Lecturer หรือ Admin จะส่งกลับพร้อมหมายเหตุ Lecturer หรือ Admin สามารถแก้เฉพาะรายที่ผิดและยืนยันสมาชิกทั้งหมดในชุดด้วยคำสั่งเดียว โดยระบบยังคงบันทึกผล ผู้ยืนยัน และเวลายืนยันแยกเป็นรายนักศึกษา

ผลหลังการตรวจสอบ:

- หากยินดีรับ ให้ยืนยันสถานประกอบการเป็นสถานที่ฝึกงาน
- หากไม่สามารถรับได้ ให้ปิดกระบวนการของสถานประกอบการนั้น และให้นักศึกษาดำเนินการกับสถานประกอบการอื่นต่อ
- นักศึกษาหนึ่งคนมีสถานที่ฝึกงานที่ยืนยันแล้วได้เพียงแห่งเดียวต่อรอบสหกิจศึกษา
- เมื่อยืนยันแล้ว สถานะสถานที่ฝึกงานของนักศึกษาคนนั้นเป็น `CONFIRMED_PLACEMENT`

เมื่อแบบตอบรับได้รับการยืนยัน กระบวนการสมัครและเอกสารของสถานประกอบการนั้นถือว่าเสร็จสิ้น

ระบบต้องบังคับข้อจำกัดหนึ่งสถานที่ฝึกงานที่ยืนยันแล้วต่อ `(นักศึกษา, รอบสหกิจ)` ที่ฐานข้อมูล การยืนยันพร้อมกันต้องสำเร็จเพียงหนึ่งรายการและต้องไม่สร้างสถานที่ฝึกงานซ้ำ

## 7. ดูสถานที่ฝึกงานที่ยืนยันแล้ว

หลังสถานประกอบการตอบรับและแบบตอบรับผ่านการตรวจสอบ นักศึกษาสามารถดู:

- ชื่อสถานประกอบการ
- ที่อยู่
- ตำแหน่งฝึกงาน
- ผู้ติดต่อของสถานประกอบการ
- วันที่เริ่มและสิ้นสุดการฝึกงาน
- สถานะการฝึกงาน
- หนังสือที่เกี่ยวข้อง
- แบบตอบรับจากสถานประกอบการ

ขั้นตอนนี้ยังไม่มีอาจารย์นิเทศ เนื่องจากจะมีการวางแผนนิเทศหลังจากนักศึกษาเริ่มฝึกงานไปแล้วระยะหนึ่ง

## 8. ดูกำหนดการนิเทศ

นักศึกษาทุกคนต้องได้รับการนิเทศสหกิจศึกษา 2 ครั้ง โดยผู้ดูแลระบบเป็นผู้วางแผนและกำหนดวันนิเทศเอง

- การนิเทศครั้งที่ 1 ดำเนินการภายในสัปดาห์ที่ 4–6 ของการปฏิบัติงาน
- การนิเทศครั้งที่ 2 ดำเนินการก่อนสิ้นสุดการปฏิบัติงาน

หนึ่งรายการนิเทศหมายถึง หนึ่งรอบการนิเทศ + หนึ่งวัน + หนึ่งช่วงเวลา + หนึ่งสถานประกอบการ โดยหนึ่งรายการมีนักศึกษาหลายคนและอาจารย์หลายคนได้ สถานะนิเทศผูกกับรายการนี้ ส่วนผลที่แตกต่างกันของนักศึกษาให้บันทึกแยกรายคนภายในรายการ

หลังสร้างตารางนิเทศแล้ว นักศึกษาสามารถดู:

- ชื่ออาจารย์นิเทศ
- ครั้งที่นิเทศ: ครั้งที่ 1 หรือครั้งที่ 2
- วันที่นิเทศ
- ช่วงเวลา
- หมายเหตุสำหรับเตรียมการ
- สถานะกำหนดการ
- การเปลี่ยนแปลงหรือการยกเลิกกำหนดการ
- ประวัติการนิเทศของตนเอง

นักศึกษาสามารถกดรับทราบกำหนดการได้ แต่ไม่สามารถกำหนดหรือเปลี่ยนอาจารย์และวันนิเทศเอง

สถานะการนิเทศแต่ละครั้งประกอบด้วย:

- จัดตารางแล้ว
- นิเทศเสร็จแล้ว
- เลื่อน
- ยกเลิก

ระบบสามารถแสดง “ยังไม่ได้จัดตาราง” บนหน้าติดตามได้ แต่ต้องคำนวณจากสถานที่ฝึกงานที่ยืนยันแล้วซึ่งยังไม่มีรายการนิเทศที่กำลังใช้งานในรอบนั้น ไม่บันทึกเป็นสถานะของรายการนิเทศ

## 9. การแจ้งเตือน

นักศึกษาควรได้รับการแจ้งเตือนภายในระบบเมื่อ:

- ส่งคำขอออกหนังสือสำเร็จ
- หนังสือถูกออกแล้ว
- หนังสือถูกส่งให้สถานประกอบการแล้ว
- ได้รับแบบตอบรับ
- แบบตอบรับได้รับการยืนยัน
- ยืนยันสถานที่ฝึกงานแล้ว
- มีการกำหนดวันนิเทศ
- วันนิเทศถูกเปลี่ยนหรือยกเลิก
- ใกล้ถึงวันนิเทศ

ระบบสามารถส่งการแจ้งเตือนไปยังอีเมลส่วนตัวของนักศึกษาเป็นช่องทางเสริมได้ แต่การแจ้งเตือนภายในระบบต้องเป็นข้อมูลหลัก หากส่งอีเมลไม่สำเร็จ นักศึกษายังต้องเห็นข้อมูลในระบบตามปกติ

## 10. ข้อจำกัดด้านสิทธิ์

นักศึกษาเข้าถึงได้เฉพาะ:

- ข้อมูลส่วนตัวของตนเอง
- สถานประกอบการที่ตนเองบันทึก
- ประวัติการสมัครของตนเอง
- หนังสือและแบบตอบรับที่เกี่ยวข้องกับตนเอง
- สถานที่ฝึกงานของตนเอง
- ตารางนิเทศของตนเอง
- การแจ้งเตือนของตนเอง

นักศึกษาไม่สามารถ:

- ดูข้อมูลหรือเอกสารของนักศึกษาคนอื่น
- ออกเลขหนังสือ
- ยืนยันแบบตอบรับ
- กำหนดอาจารย์นิเทศ
- สร้างหรือแก้ไขตารางนิเทศ
- เปลี่ยนข้อมูลที่ผู้ดูแลระบบหรืออาจารย์ยืนยันแล้วโดยไม่ได้รับอนุญาต

การตรวจสอบสิทธิ์ต้องดำเนินการที่ฝั่งเซิร์ฟเวอร์ โดยอ้างอิงตัวตนจากบัญชีที่เข้าสู่ระบบ

## 11. ลำดับการทำงาน

```text
เปิดใช้งานบัญชี
→ สมัครสถานประกอบการภายนอกด้วยตนเอง
→ บันทึกสถานประกอบการและผู้ติดต่อในระบบ
→ อัปเดตสถานะการสมัคร
→ เลือกสถานประกอบการและขอให้ออกหนังสือ
→ ติดตามหรือบันทึกการส่งเอกสาร
→ บันทึกผลตอบกลับและอัปโหลดแบบตอบรับ
→ รอผู้ดูแลระบบหรืออาจารย์ยืนยัน
→ เริ่มฝึกงาน
→ รอการวางแผนนิเทศ
→ รับแจ้งชื่ออาจารย์ วัน และเวลานิเทศ
```
