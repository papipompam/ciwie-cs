# ขอบเขตการนิเทศ ตารางนิเทศ การประเมิน และงบประมาณ

เอกสารนี้อธิบายขอบเขตการทำงาน ลำดับการดำเนินงาน และข้อมูลที่เกี่ยวข้องกับอาจารย์นิเทศ กลุ่มนิเทศ ตารางนิเทศ ผลการนิเทศ การประเมิน และงบประมาณการเดินทาง โดยเน้นมุมมองทางธุรกิจและการใช้งานของผู้ใช้

## 1. คำศัพท์ที่ใช้ในงานนิเทศ

### 1.1 รอบสหกิจศึกษา

ช่วงดำเนินงานสหกิจศึกษาที่กำหนดด้วยปีการศึกษา ภาคเรียน และรุ่นนักศึกษา ข้อมูลกลุ่มนิเทศ ตารางนิเทศ การประเมิน และงบประมาณทุกชุดต้องอยู่ภายใต้รอบสหกิจศึกษาที่ชัดเจน

### 1.2 ครั้งที่นิเทศ

ลำดับการลงนิเทศภายในรอบสหกิจศึกษาเดียวกัน เริ่มจากครั้งที่ 1 และเพิ่มได้ตามแผนงาน เช่น ครั้งที่ 1 ครั้งที่ 2 หรือครั้งที่ 3

ครั้งที่นิเทศไม่ใช่รอบสหกิจศึกษา รอบสหกิจศึกษาหนึ่งรอบสามารถมีการนิเทศได้หลายครั้ง

### 1.3 กลุ่มนิเทศหรือสายการนิเทศ

กลุ่มของสถานประกอบการที่จัดให้อาจารย์ชุดหนึ่งรับผิดชอบ โดยพิจารณาจากพื้นที่ ที่อยู่ จังหวัด พิกัด และความเหมาะสมในการเดินทาง

กลุ่มนิเทศหนึ่งกลุ่มประกอบด้วย:

- รอบสหกิจศึกษา
- ครั้งที่นิเทศ
- ชื่อกลุ่ม
- สถานประกอบการที่อยู่ในกลุ่ม
- อาจารย์ประจำกลุ่ม
- ตารางนิเทศของแต่ละสถานประกอบการ
- งบประมาณหรือแผนเดินทางที่เกี่ยวข้อง

### 1.4 อาจารย์ประจำกลุ่ม

อาจารย์ที่เจ้าหน้าที่มอบหมายให้รับผิดชอบกลุ่มนิเทศ อาจมีหนึ่งคนหรือหลายคน และเป็นรายชื่อที่ใช้สำหรับวางแผนตารางนิเทศ

### 1.5 อาจารย์ที่เข้าร่วมนิเทศจริง

อาจารย์ที่เดินทางไปนิเทศจริงในวันดำเนินงาน รายชื่อนี้อาจแตกต่างจากรายชื่ออาจารย์ประจำกลุ่มได้ในกรณีเปลี่ยนผู้เดินทาง ลาป่วย หรือมีการมอบหมายแทน

รายชื่อผู้เข้าร่วมจริงใช้สำหรับ:

- ยืนยันผู้ที่ดำเนินการนิเทศ
- กำหนดสิทธิ์ในการประเมิน
- คำนวณเบี้ยเลี้ยง
- คำนวณจำนวนห้องพักแยกตามเพศ
- เก็บเป็นประวัติของการนิเทศครั้งนั้น

### 1.6 ตารางนิเทศ

กำหนดการเข้าพบสถานประกอบการหนึ่งแห่งในครั้งที่นิเทศหนึ่งครั้ง ระบุวัน ช่วงเวลา สถานประกอบการ นักศึกษา อาจารย์ และสถานะการดำเนินงาน

หากกลุ่มหนึ่งดูแลหลายสถานประกอบการ แต่ละสถานประกอบการสามารถมีวันหรือช่วงเวลานิเทศต่างกันได้

### 1.7 ผลการนิเทศ

ข้อมูลภาพรวมที่บันทึกหลังหรือระหว่างการนิเทศ ได้แก่ สรุปผล ปัญหาที่พบ ข้อเสนอแนะ และความต้องการของสถานประกอบการ

ผลการนิเทศเป็นข้อมูลระดับการนัดหมาย ไม่ใช่คะแนนประเมินรายบุคคล

### 1.8 การประเมินนักศึกษา

แบบประเมินรายนักศึกษา โดยอาจารย์ผู้เข้าร่วมนิเทศจริงประเมินนักศึกษาแต่ละคนที่อยู่ในรายการนิเทศ

### 1.9 การประเมินสถานประกอบการ

แบบประเมินความเหมาะสมของสถานประกอบการหลังเสร็จสิ้นการนิเทศ ใช้เป็นข้อมูลประกอบการพิจารณาส่งนักศึกษารุ่นต่อไป

### 1.10 แผนเดินทางนิเทศ

แผนการเดินทางของกลุ่มนิเทศในหนึ่งวัน ระบุจุดเริ่มต้น ลำดับสถานประกอบการ ระยะทาง ผู้เดินทาง และค่าใช้จ่ายประมาณการ

แผนเดินทางหนึ่งกลุ่มสามารถมีได้มากกว่าหนึ่งวัน หากไม่สามารถเดินทางครบทุกสถานประกอบการภายในวันเดียว

## 2. ภาพรวม Flow การทำงาน

```text
  → ตรวจสอบรายชื่อนักศึกษาและอาจารย์
  → เผยแพร่ตารางนิเทศ
  → แจ้งอาจารย์และนักศึกษาที่เกี่ยวข้อง
  → อาจารย์เข้าดูตารางและรายละเอียด
  → ดำเนินการนิเทศ

  → ยืนยันว่าการนิเทศเสร็จสิ้น
  → ประเมินนักศึกษาเป็นรายบุคคล
  → ประเมินสถานประกอบการ
  → ตรวจความครบถ้วนและส่งออกข้อมูลสรุป
  → สรุปงบประมาณแยกตามแผน กลุ่ม ครั้งที่นิเทศ และรอบสหกิจศึกษา
```

## 3. ขอบเขตของเจ้าหน้าที่ในการจัดงานนิเทศ

### 3.1 จัดกลุ่มนิเทศ

เจ้าหน้าที่สามารถ:

- เลือกรอบสหกิจศึกษา
- เลือกครั้งที่นิเทศ
- ดูสถานประกอบการที่ได้รับการยืนยันแล้วในรอบนั้น
- ดูที่อยู่ จังหวัด และพิกัดของสถานประกอบการ
- ดูนักศึกษาที่ฝึกงานในแต่ละสถานประกอบการ
- จัดสถานประกอบการเป็นกลุ่มนิเทศ
- ใช้ระยะทางหรือพื้นที่ประกอบการตัดสินใจจัดกลุ่ม
- กำหนดชื่อกลุ่มนิเทศ
- ตรวจสอบว่าสถานประกอบการใดยังไม่ถูกจัดกลุ่ม
- ป้องกันสถานประกอบการเดียวกันอยู่มากกว่าหนึ่งกลุ่มในครั้งที่นิเทศเดียวกัน

### 3.2 มอบหมายอาจารย์

เจ้าหน้าที่สามารถ:

- เลือกอาจารย์ประจำกลุ่มหนึ่งคนหรือหลายคน
- ตรวจสอบอาจารย์ที่ยังพร้อมรับมอบหมาย
- ป้องกันอาจารย์คนเดียวกันอยู่หลายกลุ่มในครั้งที่นิเทศเดียวกัน
- เปลี่ยนรายชื่ออาจารย์ก่อนการนิเทศเสร็จสิ้น
- แจ้งเตือนอาจารย์เมื่อได้รับมอบหมาย
- ดูจำนวนกลุ่มและสถานประกอบการที่อาจารย์แต่ละคนรับผิดชอบ

### 3.3 สร้างและดูแลตารางนิเทศ

เจ้าหน้าที่สามารถ:

- กำหนดวันนิเทศ
- กำหนดช่วงเวลานิเทศ
- เลือกสถานประกอบการในกลุ่ม
- เลือกนักศึกษาที่จะเข้ารับการนิเทศ
- เลือกอาจารย์ที่จะเข้าร่วมตามแผน
- บันทึกเหตุผลเมื่อต้องแยกการนัดหมายออกจากตารางของกลุ่ม
- บันทึกเป็นฉบับร่าง
- เผยแพร่ตารางให้อาจารย์และนักศึกษาเห็น
- แก้ไขตารางที่ยังไม่เสร็จสิ้น
- เลื่อนนัดพร้อมเก็บเหตุผล
- ยกเลิกนัดพร้อมเก็บเหตุผล
- ตรวจสอบตารางของทุกกลุ่มในรอบเดียวกัน
- ตรวจสอบว่านักศึกษาหรือสถานประกอบการใดยังไม่มีตาราง
- ตรวจสอบความครบถ้วนของผลการนิเทศและแบบประเมิน

### 3.4 จัดทำแผนเดินทางและงบประมาณ

เจ้าหน้าที่สามารถ:

- เลือกกลุ่มนิเทศและครั้งที่นิเทศ
- กำหนดวันเดินทาง
- กำหนดจุดเริ่มต้น
- จัดลำดับสถานประกอบการที่จะเดินทางไปในวันเดียวกัน
- บันทึกระยะทางแต่ละช่วงและระยะทางรวม
- คำนวณค่าน้ำมันในอัตรา 4 บาทต่อกิโลเมตร
- ระบุอาจารย์ผู้เดินทางจริงหรือรายชื่อที่คาดว่าจะเดินทาง
- กำหนดอัตราเบี้ยเลี้ยงและจำนวนวัน
- กำหนดอัตราค่าห้องพัก จำนวนคืน และจำนวนคนต่อห้อง
- แยกจำนวนห้องพักชายและหญิง
- ดูยอดประมาณการรวม
- ดูยอดแยกตามแผน กลุ่ม ครั้งที่นิเทศ รอบสหกิจศึกษา หรือเงื่อนไขที่เลือก
- ปรับข้อมูลประมาณการเมื่อรายชื่อผู้เดินทางหรือเส้นทางเปลี่ยน

## 4. ขอบเขตของอาจารย์นิเทศ

### 4.1 ดูงานที่ได้รับมอบหมาย

อาจารย์สามารถ:

- ดูรอบสหกิจศึกษาและครั้งที่นิเทศที่ตนได้รับมอบหมาย
- ดูกลุ่มนิเทศของตนเอง
- ดูตารางนิเทศที่เกี่ยวข้องกับตนเอง
- ค้นหาตารางจากสถานประกอบการ นักศึกษา จังหวัด หรือหมายเลขนัดหมาย
- กรองตารางตามกลุ่ม ครั้งที่นิเทศ และสถานะ
- ดูวัน เวลา และสถานะของการนิเทศ
- ดูรายละเอียดสถานประกอบการและสาขา
- ดูที่อยู่และจังหวัด
- ดูรายชื่อนักศึกษาและตำแหน่งฝึกงาน
- ดูรายชื่ออาจารย์ร่วมเดินทาง
- ดูแผนการเดินทางที่เกี่ยวข้องกับกลุ่มของตน

อาจารย์ไม่ควรเห็นหรือจัดการตารางที่ไม่เกี่ยวข้องกับกลุ่มหรือการนัดหมายของตน ยกเว้นได้รับสิทธิ์เพิ่มเติมอย่างชัดเจน

### 4.2 ดำเนินการนิเทศ

ระหว่างหรือหลังการนิเทศ อาจารย์สามารถบันทึก:

- สรุปผลการนิเทศ
- ปัญหาที่พบ
- ข้อเสนอแนะ
- ความต้องการของสถานประกอบการ
- รายชื่ออาจารย์ที่เข้าร่วมจริง
- วันและเวลาที่ยืนยันว่าการนิเทศเสร็จสิ้น

ข้อมูลผลการนิเทศสามารถบันทึกไว้ก่อนได้ และควรยืนยันเสร็จสิ้นเมื่อข้อมูลพร้อมสำหรับเข้าสู่ขั้นตอนการประเมิน

### 4.3 ประเมินนักศึกษา

หลังยืนยันว่าการนิเทศเสร็จสิ้น อาจารย์ผู้เข้าร่วมจริงสามารถ:

- เลือกนักศึกษาในรายการนิเทศ
- ให้คะแนนนักศึกษาเป็นรายบุคคล
- บันทึกร่างแบบประเมิน
- กลับมาแก้ไขร่างภายหลัง
- ส่งแบบประเมินเมื่อกรอกคะแนนครบ
- ดูแบบประเมินที่ส่งแล้ว
- ส่งออกผลคะแนนและข้อเสนอแนะตามสิทธิ์ที่ได้รับ

อาจารย์หนึ่งคนประเมินนักศึกษาหนึ่งคนได้หนึ่งแบบต่อการนิเทศหนึ่งรายการ หากมีอาจารย์เข้าร่วมจริงหลายคน นักศึกษาคนเดียวกันจึงอาจมีผลประเมินจากอาจารย์หลายคน

### 4.4 ประเมินสถานประกอบการ

หลังยืนยันว่าการนิเทศเสร็จสิ้น อาจารย์ผู้เข้าร่วมจริงสามารถ:

- ให้คะแนนความเหมาะสมของสถานประกอบการ
- บันทึกข้อสังเกต
- บันทึกความต้องการของสถานประกอบการ
- บันทึกปัญหาและข้อเสนอแนะ
- ระบุคำแนะนำสำหรับการส่งนักศึกษารุ่นต่อไป
- บันทึกร่างและส่งแบบประเมิน

อาจารย์หนึ่งคนประเมินสถานประกอบการได้หนึ่งแบบต่อการนิเทศหนึ่งรายการ

### 4.5 ขอบเขตที่อาจารย์ไม่สามารถดำเนินการ

อาจารย์ทั่วไปไม่สามารถ:

- สร้างรอบสหกิจศึกษา
- เพิ่มหรือลบนักศึกษาออกจากรอบ
- ยืนยันสถานที่ฝึกงานแทนเจ้าหน้าที่
- จัดสถานประกอบการเข้ากลุ่มนิเทศ
- มอบหมายอาจารย์ให้กลุ่มอื่น
- กำหนดงบประมาณแทนเจ้าหน้าที่
- ดูหรือแก้ไขข้อมูลของกลุ่มที่ตนไม่ได้รับมอบหมาย
- ประเมินก่อนการนิเทศเสร็จสิ้น
- ประเมินนักศึกษาที่ไม่ได้อยู่ในรายการนิเทศ
- แก้ไขแบบประเมินที่ส่งสมบูรณ์แล้วผ่านขั้นตอนปกติ

## 5. Flow ของตารางนิเทศ

### 5.1 การเตรียมตาราง

1. เจ้าหน้าที่เลือกรอบสหกิจศึกษา
2. เจ้าหน้าที่ระบุครั้งที่นิเทศ
3. ระบบแสดงสถานประกอบการที่ยืนยันแล้วและนักศึกษาที่เกี่ยวข้อง
4. เจ้าหน้าที่จัดสถานประกอบการเป็นกลุ่มตามพื้นที่และพิกัด
5. เจ้าหน้าที่มอบหมายอาจารย์ประจำกลุ่ม
6. เจ้าหน้าที่กำหนดวันและช่วงเวลาของแต่ละสถานประกอบการ
7. เจ้าหน้าที่ตรวจรายชื่อนักศึกษาและอาจารย์
8. เจ้าหน้าที่บันทึกตารางเป็นฉบับร่างหรือเผยแพร่ทันที

### 5.2 การเผยแพร่ตาราง

เมื่อเผยแพร่ตาราง:

- อาจารย์ที่เกี่ยวข้องมองเห็นตาราง
- นักศึกษาที่เกี่ยวข้องมองเห็นตาราง
- ระบบแจ้งเตือนผู้ที่เกี่ยวข้อง
- ตารางเข้าสู่สถานะรอการนิเทศ
- การแก้ไขวัน เวลา หรืออาจารย์ควรแจ้งเตือนผู้ได้รับผลกระทบอีกครั้ง

### 5.3 การเปลี่ยนแปลงตาราง

หากต้องเลื่อนนัด:

1. ระบุเหตุผลการเลื่อน
2. กำหนดวันหรือช่วงเวลาใหม่
3. ตรวจสอบรายชื่อผู้เกี่ยวข้อง
4. เผยแพร่ตารางใหม่
5. แจ้งผู้เกี่ยวข้อง

หากต้องยกเลิก:

1. ระบุเหตุผลการยกเลิก
2. เปลี่ยนสถานะเป็นยกเลิก
3. ปิดการบันทึกผลและการประเมินของรายการนั้น
4. แจ้งผู้เกี่ยวข้อง

### 5.4 การปิดงานนิเทศ

1. อาจารย์เปิดรายการนิเทศที่รับผิดชอบ
2. ตรวจสอบนักศึกษาและสถานประกอบการ
3. บันทึกสรุปผล ปัญหา ข้อเสนอแนะ และความต้องการ
4. ยืนยันรายชื่ออาจารย์ที่เข้าร่วมจริง
5. ยืนยันว่าการนิเทศเสร็จสิ้น
6. ระบบบันทึกวันเวลาที่เสร็จสิ้นและล็อกข้อมูลตารางหลัก
7. ระบบเปิดให้ทำแบบประเมิน

## 6. สถานะของตารางนิเทศ

| สถานะ | ความหมาย | การดำเนินการที่อนุญาต |
| --- | --- | --- |
| ฉบับร่าง | ตารางยังไม่เผยแพร่ | เจ้าหน้าที่แก้ไข ลบ หรือเผยแพร่ได้ |
| รอการนิเทศ | ตารางเผยแพร่แล้ว | ผู้เกี่ยวข้องดูได้ และผู้มีสิทธิ์แก้ไขรายละเอียดที่จำเป็นได้ |
| เลื่อนนัด | ไม่สามารถดำเนินการตามวันเดิม | ต้องกำหนดวันใหม่หรือยกเลิก |
| นิเทศเสร็จแล้ว | บันทึกผลและผู้เข้าร่วมจริงแล้ว | เปิดให้ประเมินและจำกัดการแก้ไขตาราง |
| ยกเลิก | ยุติการนัดหมาย | อ่านประวัติได้ แต่บันทึกผลหรือประเมินไม่ได้ |

Flow ปกติ:

```text
ฉบับร่าง → รอการนิเทศ → นิเทศเสร็จแล้ว
```

Flow กรณีเลื่อน:

```text
รอการนิเทศ → เลื่อนนัด → รอการนิเทศ → นิเทศเสร็จแล้ว
```

## 7. Flow การประเมิน

### 7.1 เงื่อนไขก่อนเริ่มประเมิน

ต้องครบทุกเงื่อนไขต่อไปนี้:

- ตารางนิเทศอยู่ในสถานะนิเทศเสร็จแล้ว
- ผู้ประเมินเป็นอาจารย์ที่ได้รับมอบหมายหรือได้รับการยืนยันว่าเข้าร่วมจริง
- นักศึกษาอยู่ในรายการนิเทศนั้น
- แบบประเมินยังไม่ถูกส่งสมบูรณ์

### 7.2 การประเมินนักศึกษา

เกณฑ์คะแนนมี 6 ด้าน:

1. ความรับผิดชอบและตรงต่อเวลา
2. วินัยและจรรยาบรรณในการทำงาน
3. การสื่อสารและทำงานร่วมกับผู้อื่น
4. การประยุกต์ใช้ความรู้กับงาน
5. คุณภาพและความก้าวหน้าของงาน
6. การเรียนรู้และแก้ไขปัญหา

คะแนนแต่ละด้านใช้ระดับ 1–5:

- 1 = น้อยที่สุด
- 2 = น้อย
- 3 = ปานกลาง
- 4 = มาก
- 5 = ดีมากที่สุด

ข้อมูลประกอบการประเมินนักศึกษา:

- จุดเด่น
- ปัญหาหรือประเด็นที่พบ
- ข้อเสนอแนะ
- สิ่งที่ต้องติดตามครั้งถัดไป

### 7.3 การประเมินสถานประกอบการ

เกณฑ์คะแนนมี 13 ด้าน:

1. ความสอดคล้องของงานกับสาขาวิชา
2. ความเหมาะสมของขอบเขต ปริมาณ และความท้าทายของงาน
3. โอกาสในการเรียนรู้และพัฒนาทักษะวิชาชีพ
4. ความพร้อมของผู้ควบคุมงาน
5. การดูแลและช่วยเหลือนักศึกษา
6. สภาพแวดล้อมในการทำงาน
7. ความปลอดภัยและสุขอนามัย
8. ความพร้อมของอุปกรณ์และทรัพยากร
9. สวัสดิการ ค่าตอบแทน หรือเบี้ยเลี้ยง
10. ความสะดวกและความปลอดภัยในการเดินทาง
11. การเข้าถึงรถรับส่งหรือขนส่งสาธารณะ
12. ความเหมาะสมของที่พักใกล้สถานประกอบการ
13. การประสานงานกับมหาวิทยาลัย

ข้อมูลประกอบการประเมินสถานประกอบการ:

- ข้อสังเกตจากการนิเทศ
- ความต้องการของสถานประกอบการ
- ปัญหาที่พบ
- ข้อเสนอแนะ
- คำแนะนำสำหรับรุ่นถัดไป ได้แก่ แนะนำ แนะนำแบบมีเงื่อนไข ต้องติดตามเพิ่มเติม ไม่แนะนำ หรือมีความเสี่ยงด้านความปลอดภัย

### 7.4 สถานะแบบประเมิน

| สถานะ | ความหมาย |
| --- | --- |
| ร่าง | ยังกรอกไม่ครบหรือยังไม่ยืนยัน สามารถแก้ไขได้ |
| ส่งแล้ว | กรอกครบและยืนยันแล้ว ไม่สามารถแก้ไขผ่านขั้นตอนปกติได้ |

การบันทึกร่างสามารถมีคะแนนไม่ครบได้ แต่การส่งแบบประเมินต้องมีคะแนนครบทุกเกณฑ์

### 7.5 การส่งออกข้อมูล

ข้อมูลที่ส่งออกควรประกอบด้วย:

- รอบสหกิจศึกษา
- ครั้งที่นิเทศ
- วันนิเทศ
- สถานประกอบการ
- นักศึกษาและตำแหน่งฝึกงาน
- อาจารย์ผู้ประเมิน
- คะแนนแต่ละด้าน
- คะแนนรวมหรือคะแนนเฉลี่ยตามรูปแบบรายงาน
- จุดเด่น ปัญหา ข้อเสนอแนะ และสิ่งที่ต้องติดตาม
- ผลการแนะนำสถานประกอบการ

อาจารย์ควรส่งออกได้เฉพาะผลที่ตนมีสิทธิ์เข้าถึง ส่วนเจ้าหน้าที่สามารถส่งออกภาพรวมของรอบหรือเงื่อนไขที่เลือกได้

### 8.2 การคำนวณค่าน้ำมัน

```text
ค่าน้ำมัน = ระยะทางรวม × 4 บาท
```

อัตรา 4 บาทต่อกิโลเมตรเป็นอัตรากลางของโครงการ และควรบันทึกอัตราที่ใช้ไว้กับแผนเพื่อรักษาประวัติ แม้อัตรากลางจะเปลี่ยนในอนาคต

### 8.3 การคำนวณเบี้ยเลี้ยง

```text
ค่าเบี้ยเลี้ยง = จำนวนอาจารย์ที่เดินทาง × อัตราเบี้ยเลี้ยงต่อวัน × จำนวนวัน
```

### 8.4 การคำนวณค่าที่พัก

ระบบแยกการจัดห้องชายและหญิง โดยไม่รวมผู้เข้าพักต่างเพศในห้องเดียวกัน

```text
จำนวนห้องชาย = ปัดขึ้น(จำนวนอาจารย์ชาย ÷ จำนวนคนต่อห้อง)
จำนวนห้องหญิง = ปัดขึ้น(จำนวนอาจารย์หญิง ÷ จำนวนคนต่อห้อง)
จำนวนห้องรวม = จำนวนห้องชาย + จำนวนห้องหญิง
ค่าที่พัก = จำนวนห้องรวม × ราคาห้องต่อคืน × จำนวนคืน
```

หากอาจารย์ยังไม่มีข้อมูลเพศ ระบบควรแจ้งให้เจ้าหน้าที่แก้ไขข้อมูลก่อนยืนยันงบประมาณที่พัก

### 8.5 ยอดรวมประมาณการ

```text
ยอดรวม = ค่าน้ำมัน + ค่าเบี้ยเลี้ยง + ค่าที่พัก
```

ควรดูยอดรวมได้อย่างน้อยตามเงื่อนไขต่อไปนี้:

- รายแผนเดินทาง
- รายวัน
- รายกลุ่มนิเทศ
- รายครั้งที่นิเทศ
- รายรอบสหกิจศึกษา
- รายอาจารย์ผู้เดินทาง

- จำนวนอาจารย์ชาย
- จำนวนอาจารย์หญิง
- จำนวนห้องชาย
- จำนวนห้องหญิง
- จำนวนคนต่อห้อง
- ราคาห้องต่อคืน
- จำนวนคืน
- ค่าที่พักรวม
- อัตราเบี้ยเลี้ยงต่อวัน
- จำนวนวันเบี้ยเลี้ยง
- ค่าเบี้ยเลี้ยงรวม
- ค่าน้ำมันรวม
- ยอดรวมทั้งหมด
- ผู้บันทึก
- วันที่สร้างและแก้ไขล่าสุด

หนึ่งกลุ่มนิเทศมีข้อมูลงบประมาณล่าสุดหนึ่งรายการ เมื่อบันทึกใหม่ ระบบปรับปรุงรายการเดิมของกลุ่มนั้น

## 15. ข้อมูลที่ต้องจัดเก็บเพิ่มเพื่อให้ครบขอบเขตแผนเดินทาง

ข้อมูลต่อไปนี้ยังจำเป็นสำหรับรองรับแผนเดินทางอย่างครบถ้วน:

- รหัสแผนเดินทาง
- ชื่อแผนเดินทาง
- วันเดินทาง
- จุดเริ่มต้น
- พิกัดจุดเริ่มต้น
- ลำดับสถานประกอบการที่จะเดินทางไป
- เวลาโดยประมาณของแต่ละจุด
- ระยะทางระหว่างแต่ละจุด
- ระยะทางรวมของแผน
- อัตราค่าน้ำมันต่อกิโลเมตรที่ใช้คำนวณ
- รายชื่ออาจารย์ผู้เดินทางจริงของแผน
- สถานะของแผน เช่น ร่าง ยืนยันแล้ว หรือยกเลิก
- หมายเหตุหรือเหตุผลที่ปรับแผน
- ประวัติการแก้ไขแผน

หากไม่มีข้อมูลเหล่านี้ ระบบจะสรุปได้เพียงยอดค่าใช้จ่ายของกลุ่ม แต่ไม่สามารถอธิบายได้ว่ายอดนั้นเกิดจากเส้นทางใดหรือวันเดินทางใด

## 17. กฎทางธุรกิจที่สำคัญ

- ข้อมูลทุกชุดต้องอยู่ภายใต้รอบสหกิจศึกษาและครั้งที่นิเทศที่ชัดเจน
- ใช้เฉพาะสถานประกอบการที่ได้รับการยืนยันแล้วในการจัดกลุ่มนิเทศ
- สถานประกอบการหนึ่งแห่งอยู่ได้หนึ่งกลุ่มต่อครั้งที่นิเทศ
- อาจารย์หนึ่งคนไม่ควรถูกมอบหมายหลายกลุ่มในครั้งที่นิเทศเดียวกัน เว้นแต่มีขั้นตอนอนุมัติข้อยกเว้น
- ตารางหนึ่งรายการต้องมีสถานประกอบการ นักศึกษาอย่างน้อยหนึ่งคน และอาจารย์อย่างน้อยหนึ่งคน
- นักศึกษาในตารางต้องฝึกงานอยู่ที่สถานประกอบการของรายการนั้นจริง
- อาจารย์เห็นเฉพาะรายการที่ตนได้รับมอบหมายหรือเข้าร่วม
- ตารางฉบับร่างไม่แสดงแก่นักศึกษาและอาจารย์ทั่วไป
- ตารางที่เผยแพร่หรือแก้ไขแล้วต้องแจ้งผู้เกี่ยวข้อง
- รายการที่ยกเลิกแล้วไม่สามารถบันทึกผลหรือประเมินได้
- การประเมินทำได้หลังการนิเทศเสร็จสิ้นเท่านั้น
- ผู้ประเมินต้องเป็นอาจารย์ที่ได้รับมอบหมายหรือเข้าร่วมจริง
- แบบประเมินที่ส่งแล้วไม่แก้ไขผ่านขั้นตอนปกติ
- ค่าน้ำมันคำนวณจากระยะทางรวมในอัตรา 4 บาทต่อกิโลเมตร
- การจัดห้องพักต้องแยกเพศ
- งบประมาณต้องเก็บรายชื่ออาจารย์และอัตราที่ใช้คำนวณเป็นข้อมูล ณ เวลานั้น เพื่อไม่ให้ยอดย้อนหลังเปลี่ยนตามข้อมูลปัจจุบัน
- เมื่อปิดรอบสหกิจศึกษา ข้อมูลตาราง ผลการนิเทศ การประเมิน และงบประมาณควรเป็นประวัติแบบอ่านอย่างเดียว

## 18. กรณีพิเศษที่ระบบควรรองรับ

### 18.1 อาจารย์ตามแผนไม่ได้เดินทางจริง

เก็บรายชื่อเดิมไว้เป็นแผน และบันทึกรายชื่อผู้เข้าร่วมจริงแยกต่างหาก การประเมินและค่าใช้จ่ายจริงยึดรายชื่อผู้เข้าร่วมจริง

### 18.2 สถานประกอบการเดียวมีนักศึกษาหลายคน

สร้างตารางนิเทศหนึ่งรายการสำหรับสถานประกอบการ และเชื่อมนักศึกษาทุกคนที่เข้ารับการนิเทศไว้ในรายการเดียวกัน จากนั้นประเมินนักศึกษาแยกเป็นรายบุคคล

### 18.3 สถานประกอบการเดียวต้องนิเทศหลายวัน

สร้างรายการนิเทศหรือแผนเดินทางแยกตามวันที่ โดยต้องไม่ทำให้การประเมินซ้ำโดยไม่ตั้งใจ

### 18.4 ตารางถูกเลื่อนหลังเผยแพร่

เก็บเหตุผลการเลื่อน กำหนดวันใหม่ และแจ้งอาจารย์กับนักศึกษาทุกคนที่ได้รับผลกระทบ

### 18.5 เปลี่ยนผู้เดินทางหลังคำนวณงบประมาณ

คำนวณเบี้ยเลี้ยงและห้องพักใหม่ พร้อมเก็บเวลาที่แก้ไขและข้อมูลผู้เดินทางชุดใหม่

### 18.6 อาจารย์ไม่มีข้อมูลเพศ

ยังคำนวณค่าน้ำมันและเบี้ยเลี้ยงได้ แต่ไม่ควรยืนยันค่าที่พักจนกว่าจะมีข้อมูลเพศครบหรือเจ้าหน้าที่ระบุวิธีจัดห้องอย่างชัดเจน

### 18.7 แบบประเมินถูกส่งผิด

ไม่ควรเปิดให้แก้ไขโดยตรง ต้องมีกระบวนการส่งกลับหรือปลดล็อกโดยผู้มีอำนาจ พร้อมบันทึกเหตุผลและประวัติ
